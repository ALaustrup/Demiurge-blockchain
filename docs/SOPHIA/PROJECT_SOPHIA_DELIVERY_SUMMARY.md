## 🏗️ The Design (Summary)

### User Experience
```
Landing (3-5s animated intro)
    ↓ "Enter Portal"
QOR ID Auth Gate (secure login/signup)
    ↓ Authenticate
Dashboard (game launcher aesthetic with system grid)
    ├─ Mining Portal
    ├─ Wallet (CGT Balance)
    ├─ NFT Portal (DRC-369)
    ├─ Games Launcher
    ├─ Game Dev SDK
    ├─ Chain Dev Tools
    ├─ Knowledgebase
    └─ Sophia Chat (floating button)
```

### Sophia (The AI Gatekeeper)
**6 Core Capabilities**:
1. **Navigation** - "Take me to wallet" → Routes to system
2. **Education** - "What's CGT?" → Explains blockchain concepts
3. **Account Ops** - "Change password" → 2FA verification gate
4. **Status** - "How's the network?" → Real-time blockchain stats
5. **Personalization** - Learns user behavior & suggests relevant systems
6. **Insights** - "What should I do?" → Personalized recommendations

### Security Model
- QOR ID (username-based, not wallet-dependent)
- JWT authentication (15-min tokens, 30-day refresh)
- 2FA for sensitive operations
- HTTPS, CORS, CSP headers
- HttpOnly cookies
- Rate limiting (20 msgs/min, 5 attempts/15min)
- Audit logging of all operations
