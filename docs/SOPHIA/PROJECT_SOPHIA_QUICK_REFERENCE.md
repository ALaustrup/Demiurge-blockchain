# 🧙‍♀️ PROJECT SOPHIA - Quick Reference Card\n\n**Keep This Handy While Building**\n\n---\n\n## The Vision (One Sentence)\n\n> Build `demiurge.cloud` - an immersive, AI-powered portal where Sophia guides users through the entire Demiurge ecosystem.\n\n---\n\n## The Flow (30 Seconds)\n\n```\n1. User lands on demiurge.cloud\n2. Sees beautiful 3D intro animation (3-5s)\n3. Clicks \"Enter Portal\" → QOR ID auth gate\n4. Logs in/signs up\n5. Lands on game launcher-like dashboard\n6. Sees system grid (Mining, Wallet, NFT, Games, Dev, Knowledge)\n7. Sophia floats in bottom-right: \"What would you like to explore?\"\n8. User clicks system or asks Sophia → Portal loads\n```\n\n---\n\n## Key Components (Build These)\n\n| Component | Purpose | Status | Phase |\n|-----------|---------|--------|-------|\n| Landing Page | Intro animation | 🚧 TBD | 1 |\n| QOR ID Auth | Login/signup | ✅ Integrate | 1 |\n| Dashboard | System grid | 🚧 TBD | 1 |\n| System Grid | Card selector | 🚧 TBD | 1 |\n| Portal Embed | Iframe wrapper | 🚧 TBD | 2 |\n| Portal Bridge | PostMessage comm | 🚧 TBD | 2 |\n| Sophia Chat | AI assistant | 🚧 TBD | 3 |\n| Account Settings | User management | 🚧 TBD | 3 |\n| 2FA Verification | Security gate | 🚧 TBD | 3 |\n\n---\n\n## Tech Stack (What to Use)\n\n**Frontend**\n- Next.js 16+ (App Router)\n- TypeScript\n- Tailwind CSS\n- Framer Motion (animations)\n- React Context + Zustand (state)\n\n**Backend/AI**\n- Vercel AI SDK (Claude/GPT)\n- REST endpoints\n- Tool calling (navigation, account ops)\n\n**Integration**\n- QOR Auth (JWT)\n- Blockchain RPC (stats)\n- Iframe (portals)\n- PostMessage (bridge)\n\n---\n\n## Environment Variables (Set These)\n\n```bash\n# Auth\nNEXT_PUBLIC_QOR_AUTH_URL=http://localhost:3001\nQOR_AUTH_SECRET=your_secret\n\n#
