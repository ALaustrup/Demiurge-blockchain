# DRC-369: The Metaversal NFT Standard

> **The World's Premier Universal NFT Infrastructure for Metaverse Assets**

DRC-369 is a comprehensive, cross-chain, cross-metaverse NFT standard designed for true digital asset interoperability. It treats NFTs as first-class citizens of the metaverse - not just static images, but living, evolving digital assets that can exist and function across any virtual world, blockchain, or game engine.

## Overview

### Core Philosophy

DRC-369 is built on the principle that NFTs should be **portable, functional, and valuable** across the entire digital ecosystem. Whether your asset is a sword in a game, an avatar in VRChat, or a piece of virtual real estate, DRC-369 ensures it works everywhere.

### Key Differentiators

| Feature | DRC-369 | ERC-721 | ERC-1155 |
|---------|---------|---------|----------|
| Cross-Chain Identity | ✅ UNID | ❌ | ❌ |
| Metaverse Portability | ✅ Native | ❌ | ❌ |
| Dynamic State | ✅ XP, Levels, Stats | ❌ | ❌ |
| Physics Properties | ✅ Game Engine Ready | ❌ | ❌ |

### Standards Compliance

- **ERC-721 Compatible**: Seamless bridging to Ethereum/EVM chains

- **Open Metaverse Interoperability (OMI)**: Full compliance
- **Metaverse Standards Forum (MSF)**: Active participation
- **Virtual Asset Metadata Standard (VAMS)**: Supported

## Universal Identity (UNID)

Every DRC-369 NFT has a **Universal NFT Identifier** that works across all blockchains and metaverses.

### Format

```
did:drc369:<chain_id>:<contract_address>:<token_id>
```

### Examples

```
# Native Demiurge NFT
did:drc369:demiurge:0x1234...5678:0xabcd...ef01

# Bridged from Ethereum
did:drc369:ethereum:0xBC4CA0EdA7647A8aB7C2061c2E118A18a936f13D:1234

# Bridged from Polygon
did:drc369:polygon:0x2953399124F0cBB46d2CbACD8A89cF0599974963:5678
```

### Bridge Provenance

DRC-369 tracks the complete history of an NFT across chains:

```json
{
  "origin_chain": "ethereum",
  "origin_token_id": "0x1234...",
  "bridge_history": [
    {
      "from_chain": "ethereum",
      "to_chain": "polygon",
      "timestamp": 1706745600,
      "bridge_protocol": "LayerZero"
    },
    {
      "from_chain": "polygon",
      "to_chain": "demiurge",
      "timestamp": 1706832000,
      "bridge_protocol": "native"
    }
  ],
  "current_chain": "demiurge",
  "is_canonical": false
}
```

## Dynamic State System

DRC-369 NFTs can evolve over time with XP, levels, and custom stats.

### State Structure

```json
{
  "xp": 15000,
  "level": 15,
  "stats": {
    "strength": 50,
    "agility": 35,
    "intelligence": 80,
    "charisma": 45
  }
}
```

### Leveling System

- **XP Threshold**: 100 XP per level (configurable)
- **Max Level**: Unlimited
- **Stat Scaling**: Optional per-level bonuses

### RPC Methods

```bash
# Add XP
curl -X POST https://rpc.demiurge.cloud:9944 \
  -d '{"jsonrpc":"2.0","id":1,"method":"drc369_addXp",
       "params":["TOKEN_ID", 500, "SIGNATURE"]}'

# Get state
curl -X POST https://rpc.demiurge.cloud:9944 \
  -d '{"jsonrpc":"2.0","id":1,"method":"drc369_getState",
       "params":["TOKEN_ID"]}'
```

## Fractional Ownership

Split high-value NFTs into tradeable shares.

### How It Works

1. **Fractionalize**: Convert 1 NFT into N shares
2. **Trade**: Shares are fungible and tradeable
3. **Govern**: Shareholders vote on NFT decisions
4. **Buyout**: Offers to reconstitute the NFT
5. **Reconstitute**: 100% holder merges shares back

### Configuration

```json
{
  "total_shares": 10000,
  "symbol": "PUNK-1234",
  "name": "Fractional CryptoPunk #1234",
  "governance_threshold_bps": 100,
  "buyout_enabled": true,
  "min_buyout_price": "1000000000000000000",
  "curator": "0x...",
  "curator_fee_bps": 250
}
```

### Governance

Shareholders can vote on:
- Curator changes
- Metadata updates
- Buyout settings
- Marketplace listings
- NFT reconstitution

## Security Features

### Emergency Freeze

Instantly freeze NFTs in case of theft or hack:

```bash
# Freeze NFT for 72 hours
curl -X POST https://rpc.demiurge.cloud:9944 \
  -d '{"jsonrpc":"2.0","id":1,"method":"drc369_freeze",
       "params":["TOKEN_ID", "SuspectedTheft", 259200, "SIGNATURE"]}'
```

### Freeze Reasons

- `SuspectedTheft`: Reported stolen
- `LegalHold`: Compliance requirement
- `SuspiciousActivity`: Anomaly detected
- `OwnerRequest`: Owner-initiated
- `Dispute`: Marketplace dispute
- `SecurityVulnerability`: CVE response

### Multi-Signature

Require N-of-M signatures for transfers:

```json
{
  "required_sigs": 2,
  "signers": ["0xAlice...", "0xBob...", "0xCharlie..."],
  "enabled": true
}
```

### Rate Limiting

Prevent rapid suspicious transfers:

```json
{
  "max_transfers": 5,
  "period_seconds": 86400,
  "enabled": true
}
```

### Cooldowns

Time locks after actions:

```json
{
  "transfer": 3600,
  "battle": 300,
  "breeding": 86400
}
```

### Social Recovery

Guardian-based key recovery:

```json
{
  "guardians": ["0xGuardian1...", "0xGuardian2...", "0xGuardian3..."],
  "required_approvals": 2,
  "recovery_delay": 172800
}
```

## SDK Usage

### TypeScript

```typescript
import { DemiurgeClient, DRC369 } from '@demiurge/sdk';

const client = new DemiurgeClient('wss://rpc.demiurge.cloud:9944');

// Mint with all features
const nft = await DRC369.mint(client, {
  owner: wallet.address,
  metadata: {
    name: 'Epic Sword',
    description: 'A legendary weapon',
    image: 'ipfs://...'
  },
  metaverseCompatibility: {
    platforms: ['Demiurge', 'VRChat'],
    assetFormats: [
      { type: 'Model3D', format: 'glb', contentId: 'ipfs://...' }
    ]
  },
  physics: {
    rigidBody: { mass: 5.0, friction: 0.3 },
    collision: { shape: 'ConvexHull' }
  },
  royalty: {
    recipient: wallet.address,
    percentageBps: 500
  },
  equipmentSlots: [
    { slotType: 'Weapon', name: 'Main Hand' }
  ]
});

console.log('Minted:', nft.unid.toDid());
```

### React Component

```tsx
import { useNFT, useNFTState } from '@demiurge/react';

function NFTCard({ tokenId }: { tokenId: string }) {
  const { nft, loading } = useNFT(tokenId);
  const { state, addXp } = useNFTState(tokenId);

  if (loading) return <div>Loading...</div>;

  return (
    <div className="nft-card">
      <img src={nft.metadata.image} alt={nft.metadata.name} />
      <h3>{nft.metadata.name}</h3>
      <p>Level: {state.level} | XP: {state.xp}</p>
      <p>UNID: {nft.unid.shortId()}</p>
      <button onClick={() => addXp(100)}>+100 XP</button>
    </div>
  );
}
```
